Cable-First Transfer

Primary path: cable/native transfer for best speed and stability. Fallback to wireless only if cable path is unavailable.

Step 1: Enter Second Code

Cable mode is active and unlocked with its own code.

This code is separate from the normal upload page code.

Step 2: Connect Cable

iPhone / iPad to Windows

Use a trusted USB cable and unlock the iPhone/iPad. If prompted, tap "Trust This Computer".

Apple Native Transfer

Use Apple Devices (Windows app), Finder/iTunes workflows, or native import/export tooling for high-speed cable transfer.

Fallback To Wireless

  • Use LocalSend on both devices when cable is unavailable.
  • Use SMB share on local network if supported in your setup.
  • Use browser upload/download through Drop Air as a final fallback.
