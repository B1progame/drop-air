# Drop Air 1.6.10

The Windows installer now lets you choose a normal installation or a portable installation.

## Installation choices

- **Normal:** Creates a Start menu shortcut and optionally a desktop shortcut. Settings, uploads, and logs stay in the per-user Drop Air data folder.
- **Portable:** Keeps settings, uploads, and logs in a `data` folder beside the launcher. No shortcuts are created. The app can be moved together with that folder.
- The standalone portable ZIP uses the same folder-based data layout.

The release bundle includes the Windows setup installer, portable ZIP, and SHA256 checksums.
