# Drop Air 1.1.5

Drop Air 1.1.5 fixes packaged updater restarts so newly installed versions launch cleanly after the silent installer finishes. This release also keeps the in-app updater progress page from 1.1.4 so update status remains visible without the terminal.

## New

- Added tracked release notes under `release-notes/` so notes can be committed without using ignored root release-note files.

## Changed

- The updater restart handoff now forces PyInstaller to create a fresh runtime environment when launching the updated app.
- Source-mode restarts now use the same fresh PyInstaller environment flag for consistency.

## Fixed

- Fixed updated packaged installs sometimes failing with `Failed to load Python DLL ... _MEI... python311.dll`.
- Fixed the post-install restart inheriting stale PyInstaller one-file extraction state from the old app process.

## Checks

- `python -m compileall app.py`
- `python -m unittest discover -s tools -p "test_*.py"`
