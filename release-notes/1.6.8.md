# Drop Air 1.6.8

Drop Air 1.6.8 improves startup responsiveness, clipboard importing, transfer throughput, progress feedback, and the Windows self-updater.

## Changes

- Matched both startup skeleton renderers to the supplied list-row reference with circular avatars, varied text bars, neutral placeholders, and no periodic animation repaint.
- Added native desktop clipboard reading for pasted text and images when Chromium cannot access the clipboard on the local HTTP origin.
- Avoided writing each uploaded file twice by atomically publishing the staged file with a same-volume hard link when supported; retained a safe copy fallback for filesystems that reject links.
- Added percentage, rolling transfer speed, and estimated time remaining inside the upload progress bar, with accessible progress semantics.
- Fixed the updater’s misleading progress display that climbed to 95% and stayed there while waiting for Windows Setup.
- Run the installer with elevation, pass the current installation directory, save an Inno Setup log, and verify `VERSION` before restarting Drop Air.
