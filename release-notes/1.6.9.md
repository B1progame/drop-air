# Drop Air 1.6.9

Drop Air 1.6.9 fixes slow or stalled startup and makes launch state visible while the dashboard loads.

## Changes

- Avoid synchronous hostname/DNS lookup when binding the local threaded server.
- Show the supplied three-row skeleton with live startup phases, dashboard load percentage, and subtle activity dots while startup proceeds.
- Defer WebEngine imports until the first skeleton frame is visible and keep all Qt widgets and WebEngine setup on the GUI thread.
- Add 45-second per-stage startup timeouts, a dashboard retry action, renderer-crash handling, and startup diagnostics.
- Keep a native launcher watchdog active until the dashboard reports ready; automatically launch the saved previous version if the core never opens successfully.
- Fix rollback launch so it waits for the failing window to exit instead of merely focusing that window.
